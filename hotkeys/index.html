What differs from the repo

Fourteen added alternates. Nothing else removed, nothing moved.

  • P Gather — the pad has no Y key
  • ` trash group, Shift+` last alert — no BackSlash key
  • O on all six group-6 commands, because the pad's Caps Lock now sends O
  • Four landing points for Karabiner's rerouted chords, never pressed directly
  • G5 as a single-key select all army, with no Command modifier to be intercepted

The one dependency

SC2 for macOS rewrites every Control in the file to Command, and this pad has no Command key. Karabiner supplies it and reroutes three chords macOS will not release.

If Karabiner is not running, every add-to-group silently stops. It looks like the profile broke. Check Karabiner first.

Reading the pad

  • Switch modifier layer to see what the same key does under Shift, Alt, Ctrl.
  • Switch race and selected building to see the command card that key sends.
  • Click a legend chip to isolate one role. Click any key for every meaning it carries.
  • Live keys listens to your real keyboard: press a key on the pad and it lights up, hold a modifier and the layer follows. This is the non-destructive way to check what a key really sends.

Every game, before anything else

Key bindings load with the profile. Control groups and cameras are empty at the start of every match, which is what this is for. It is TheCore's own documented start sequence.

Start sequence

  1. Hold Space as the map loads, click the Nexus. Probes first.
  2. Thumb parks on Alt and stays there.
  3. Alt+Tab centre · Alt+Q add Nexus to W · Alt+A main camera.
  4. Pointer on the ramp, Alt+W rally camera.
  5. Alt+S Alt+Z Alt+X on future expansions.

Warp-in — Shift stays down

  1. Shift+Q grabs production. Warp Gates take selection priority, so the card shows warp-in units.
  2. Shift+3 jumps to the forward pylon.
  3. Hold Shift+D and sweep the mouse. One Zealot per gate, no clicking.
  4. Shift+W back to the rally camera.

The two macro groups

Q holds every army production building: Gateways and Warp Gates, plus Robotics Facility and Stargate. W holds Nexuses plus every research building: Cybernetics Core, Forge, Twilight Council, Robotics Bay, Templar Archive, Fleet Beacon.

The split is what a building does, not where it sits in the tech tree. Robotics Facility makes units so it is Q; Robotics Bay only researches so it is W. Same for Stargate and Fleet Beacon.

Ctrl+key adds to a group, Ctrl+Shift+key creates one. Both steal, meaning the units leave whatever group they were in. That is TheCore's deliberate default. One upstream quirk: Ctrl+W also fires ToggleWorldPanel, so prefer Alt+Q for the Nexus group, which is the same command and already in the start sequence.

Two-week transition

  1. Days 1-3, no ladder. Custom vs AI, drilling only W, probes, chrono, Q, warp round.
  2. Days 4-7, the 7:00 build vs AI, cameras set every game.
  3. Week 2, 2v2 only, where the stakes are lower.
  4. Day 14, re-measure the two numbers you baselined before switching. Probe utilisation at minute 6 and unspent minerals at 7:00 are the ones that move first.

Expect to lose games in week one. Whatever you have most recently fixed in your macro is running on muscle memory that this layout invalidates, so baseline it before you switch and measure again at day 14 rather than panicking at day 3.

The larva trick, and its exceptions

Hatchery, Lair and Hive carry select-larva as an alternate on six production keys, so one press does both jobs: Space Drone, D Zergling, R Roach, C Hydralisk, T Corruptor, G Ultralisk. Every key on the dense card stays useful when a Hatchery is selected.

Five units are deliberately left off that list and need larva selected first: Overlord E (shares the key with Queen, so E is the Zerg mineral-only macro key), Infestor F (shares with the Lair and Hive morph), Mutalisk V, Viper 4 and Swarm Host 5. TheCore's stated reason is that these are casters or situational units, and that dumping a whole round of larva into them by accident loses games.

Left open

Two things the file does not settle

  • Inject has no explicit binding. The only inject line in the file, InjectLarva/Queen, is present but empty. The documented workflow uses Shift+Space, which is the all-units "useful ability" slot, so inject appears to ride SC2's own default rather than an explicit line. That is an inference, not a verified fact. Press it in a custom game before trusting it in a ladder match.
  • Roach Warren and Spire share R in the Drone advanced menu. Both are bound to R in the file. As with the Terran collision, AllowSetConflicts=1 means SC2 accepts it and cycles, but it will cost a press.

Every non-obvious choice, why it was made, and what it costs. Decisions marked open are unverified or deliberately deferred.

1. Run TheCore Lite Nordic essentially unmodified

2026-09-18 · settled

Context. A one-handed pad invites heavy customisation, and the first pass drifted that way.

Decision. The installed file is the upstream Nordic/TheCore Lite.SC2Hotkeys plus seven added alternates and zero removals. Every addition traces to a physical key the pad lacks.

Why. Fidelity means the community docs, the PDF cheatsheet and Joosep's setup all still describe this keyboard. Convenience bindings would quietly fork it.

Cost. Some upstream quirks are inherited rather than fixed, notably the Ctrl+W / ToggleWorldPanel conflict.

2. Install to the per-account folder, not the documented one

2026-09-18 · settled

Context. The profile did not appear in SC2's dropdown at all.

Decision. Profiles live in .../StarCraft II/Accounts/<id>/Hotkeys/.

Why. TheCore's install doc names the top-level StarCraft II/Hotkeys/, and SC2 will happily create it, but this installation reads only the per-account folder. A profile in the wrong one fails silently, with no error and no list entry.

3. Gather to P. Move stays unbound

2026-09-18, revised 2026-09-20 · settled

Context. The pad has no H and no Y. Upstream puts Move on H with no alternate, and Gather on Y.

Decision. Gather gets P as an alternate. Move gets nothing. Right click issues a move and costs no key at all, so a Move key is a binding to remember for a case the mouse already covers.

Revised. N was added as a Move alternate on 18 September and removed on 20 September. The original reasoning was that right click will not move onto a unit without interacting with it. True, and judged not worth a key. Fewer bindings beat completeness on a pad this small.

Consequence. Move=H is now byte-identical to upstream, and N is a dead key on this pad.

4. Tilde key carries the trash group

2026-09-19 · open

Context. The Nordic variant moves US TheCore's Grave bindings onto BackSlash, which this pad does not have. The pad's tilde key was therefore dead.

Decision. Bind the trash group and alert recall to OEM102 as well.

Why that name. The pad is ANSI hardware under a Nordic software layout, so its tilde position reports as the ISO extra key. An earlier profile on the same machine used ArmySelect=OEM102 for this physical key, so SC2 accepts the name here.

Still open. Inferred, not confirmed in game. If the name is wrong the two lines do nothing and nothing breaks.

5. Remap the pad's Ctrl to Command rather than abandon the layer

2026-09-19 · settled

Context. SC2 for macOS rewrites every Control in a hotkey file to Command and exposes no Control modifier at all. The pad has no Command key, so the entire add-to-group layer was unreachable.

Decision. Remap the pad's Control to Command, scoped to that one keyboard.

Alternatives rejected. Using Shift+Alt for group editing, which breaks the Ctrl-means-add association. Rebinding the file away from Control, which forks it.

Cost. A hard dependency on Karabiner running. See decision 6 for why the built-in macOS remap was not enough.

6. Karabiner, not the built-in modifier remap

2026-09-20 · settled

Context. Once Ctrl became Command, three chords were swallowed by macOS before SC2 saw them: Cmd+Tab (app switcher), Cmd+Shift+3 (screenshot) and Cmd+Shift+Q (Log Out). All three were hit in real play.

Decision. Karabiner-Elements does both jobs: Control to Command, and rerouting those three chords to Cmd+Opt variants macOS has no claim on. Three matching alternates were added to the hotkey file as landing points.

Alternatives rejected. Disabling the macOS screenshot shortcut, which the author uses daily. Overriding the Apple menu's Log Out through App Shortcuts, which breaks if the account name changes. Avoiding Ctrl+Shift by habit, which fails exactly when you are under pressure.

Cost. A third-party driver with a system-extension approval, and a silent failure mode if it stops running.

7. G2 to G5 left unbound

2026-09-20 · deferred

Context. The five G keys send F1 to F5. G1 lands on F1, which is idle worker, a useful accident. G2 to G5 are free.

Decision. Leave them empty until the day-14 review.

Why. The obvious candidates are single-key camera jumps, whose value depends on the Alt+A/S/Z/X habit being automatic. A key that jumps to a third base is worth nothing while the third base is not down inside ten minutes.

Note. G2 briefly carried select-all-army, and was freed again once Karabiner could route Ctrl+Tab.

Resolved for G5, 20 September. The G keys are not distinct keys: G1 to G4 send F1 to F4, which the top row also sends, so G2 could never mean anything other than its twin. Only G5 sends F5, which has no twin on this pad and no binding in the file. Select all army now carries F5 as a fifth alternate, so it has a single-key form with no Command modifier for macOS to intercept. G3 and G4 stay free.

8. Never test unsupported keys in SC2's hotkey editor

2026-09-19 · hard-won

What happened. Pressing Ctrl into a binding field, to see whether SC2 accepted Control, cleared that binding and cascaded: ControlGroupAppendAndSteal4 was emptied and the 4 key was stripped from about twenty other commands, including Forge/Probe=4.

Rule. Test key names in a throwaway duplicate profile, never the live one. Recovery is to reinstall from ~/SC2/hotkeys-src/ while SC2 is closed, since SC2 rewrites the file on exit.

9. Conflict dialog on launch: always Ignore

2026-09-19 · settled

Context. SC2 reports "HOTKEY CONFLICTS DETECTED" every launch.

Decision. Ignore, never Resolve. The duplicate-key list is byte-identical to the pristine upstream file, so these are TheCore's deliberate overlaps, which is why it ships AllowSetConflicts=1. Resolve opens the editor from decision 8.

10. Provenance: what is TheCore's and what is not

2026-09-20 · settled

Every key table here was machine-checked line by line against the upstream file, 118 of 118 exact matches. The role logic, the Q/W split, the start sequence, the warp-in sequence and the RapidFire semantics are TheCore's own documentation.

The 20-second macro loop and the two-week transition plan are not from TheCore. The word "loop" does not appear in its README at all, and its only Protoss routine is a chrono variant. Those two came from replay analysis of one player and are marked as such throughout. Treat them as an example of method, not as part of the layout.

12. Chord rules must carry optional: any

2026-09-20 · hard-won

What happened. Select all army stopped working in real games, and sometimes the macOS app switcher appeared instead. The binding was intact in the file and Karabiner was running, which is what made it hard to see.

Cause. A Karabiner from.modifiers.mandatory list with no optional entry matches only when those modifiers are the exact set held. The three chord rules named one or two modifiers each. TheCore parks the thumb on Alt and keeps Shift down through warp-in and inject, so a third modifier is usually present, no chord rule matched, and the catch-all passed Cmd+Shift+Tab straight to macOS.

Decision. Every chord manipulator now carries "optional":["any"], and ArmySelect gained a fourth alternate, Control+Alt+Shift+Tab, because an optional Shift is passed through to the output.

Rule to keep. A modifier list without optional is a bug on a layout whose whole method is holding modifiers down.

13. The pad's Caps Lock sends O

2026-09-20 · settled

Context. TheCore puts six commands on Caps Lock: recall, append, assign, both steal variants, and centre-on-selection. On macOS Caps Lock is a locking key. It registers only after a hold delay, toggles the lock state and the LED, and does not deliver a clean press and release. Group 6 felt unreliable and chat came out in capitals.

Decision. Karabiner remaps the pad's caps_lock to o, scoped to the pad as every other rule is, and the six commands gained an O alternate. Nothing was removed.

Why O. The pad has no O key, so there is nothing to collide with physically, and TheCore binds O to nothing in multiplayer. The one global use is ObserveCommentator=O, which only matters in observer mode.

Cost. The pad can no longer type a capital letter, which is irrelevant on a gaming-only keypad, and the printed cheatsheet's Caps Lock column now needs reading as O.

11. Terran and Zerg documented from the file, not from play

2026-09-20 · open

Context. The page covered one race, which made it a personal cheatsheet rather than a description of the layout. TheCore's whole building-consistency argument only shows up when all three are on the page next to each other.

Decision. Add Terran and Zerg tabs built the same way the Protoss one was, by reading the installed .SC2Hotkeys file and TheCore Lite's README, and add nothing from memory or from general SC2 knowledge.

Cost. Neither tab has been played on this pad. There are no drills on them, and two upstream key collisions are flagged rather than resolved: ResearchSiegeTech against ResearchSmartServos on the Factory Tech Lab, and Roach Warren against Spire in the Drone advanced menu. The empty InjectLarva/Queen line is flagged the same way.

Why keep it open. A tab that claims to be verified when nobody has played the race is worse than one that says plainly which parts are inferred.

Order of operations

Quit SC2 before touching the hotkey file. SC2 rewrites it on exit and will silently discard your edits.

  1. Drop the .SC2Hotkeys file into ~/Library/Application Support/Blizzard/StarCraft II/Accounts/<your-id>/Hotkeys/. Not the top-level Hotkeys folder.
  2. Install Karabiner-Elements. Approve the system extension in Privacy & Security and grant Input Monitoring.
  3. Find your pad's IDs with hidutil list and put them in the config below.
  4. Launch SC2, pick the profile in Options → Hotkeys, click Ignore on the conflict dialog.

Karabiner rules

Goes in ~/.config/karabiner/karabiner.json under the selected profile's complex_modifications.rules. Eight manipulators, all scoped by device_if so no other keyboard is touched. Vendor 12815 is 0x320f and product 20480 is 0x5000, which is how the DITI identifies itself.

Each chord rule appears twice, once matching left_control and once left_command. That is not redundancy. Karabiner matches from.modifiers against the physical modifier, not the remapped one. The first version of this config only matched left_command, the chords fell straight through, and Ctrl+Shift+Q quit the front application.

Every chord rule carries "optional":["any"]. Without it, a rule matches only when its named modifiers are the exact set held. TheCore parks the thumb on Alt and keeps Shift down through warp-in and inject, so in real play a third modifier is almost always present, the reroute silently stopped matching, and the catch-all handed macOS a raw Cmd+Shift+Tab or Cmd+Shift+Q. That is a game losing focus mid-fight, not a missing hotkey.

The pad's Caps Lock is remapped to O. Caps Lock is a locking key: macOS holds it for a moment before it registers, toggles the lock and the LED, and does not deliver a clean press and release. TheCore puts six commands on it. O is the fix because the pad has no O key and TheCore uses O nowhere in multiplayer, so the six group-6 lines simply gained an O alternate.

To check what a key really sends, open any page with a console and log keydown events. That is how the G keys were found to be F1 to F5, the globe key to be M, and the chord routing to be working. It is non-destructive, unlike SC2's own hotkey editor.
